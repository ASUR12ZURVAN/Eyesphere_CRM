CSV Format Guidelines

Prepare your CSV

  • Save or export the file as .csv; Excel workbook files are not accepted. The file must be no larger than 5 MB.
  • Include a header row. Header names are matched without regard to capitalization or surrounding spaces.
  • Each row must have a non-empty Name, Mobile, and Source.
  • Accepted header alternatives: Name / Patient Name / Lead Name; Mobile / Phone / Phone Number / Mobile Number; Source / Lead Source.
  • Optional columns are Campaign (or Campaign Name), Location (or City / Area), Email (or Email Address), and External Source ID (or External ID / Row ID). Leave unused optional values blank.
  • Use a valid phone number containing 8–15 digits. Separators such as spaces, parentheses, plus signs, and hyphens are removed. A 10-digit number is treated as an Indian number and prefixed with +91; an 11-digit number beginning with 0 has that leading zero removed.
  • Source must match one of these values or labels: META / Meta, GOOGLE / Google, CORPORATE / Corporate, CAMP / Camp, OFFLINE / Offline, REFERRAL / Referral, WEBSITE / Website, WHATSAPP / WhatsApp, or OTHER / Other.
  • Do not repeat a mobile number or External Source ID within the file. Existing mobile numbers are marked as duplicates in preview; rows with an already-imported External Source ID are skipped during confirmation.
